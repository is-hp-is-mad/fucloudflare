# Fonts embedded in the panel

Latin subsets, variable weight, as published by Fontsource (npm
`@fontsource-variable/*@5.1.0`), served by the API at `/fonts/<file>`.

| File | Family | Licence |
|---|---|---|
| `inter-latin-wght.woff2` | Inter | SIL OFL 1.1, `LICENSE-Inter.txt` |
| `source-serif-4-latin-wght.woff2` | Source Serif 4 | SIL OFL 1.1, `LICENSE-SourceSerif4.txt` |

Chinese text falls back to the system's fonts (PingFang SC, Noto Sans/Serif SC, …).
